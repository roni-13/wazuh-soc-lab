# Windows Failed Logon Detection — Event ID 4625

## Overview

This use case demonstrates detection of failed Windows authentication attempts using Wazuh.

Windows Event ID **4625** is generated when an account logon attempt fails. Wazuh monitors the Windows security event and generates an alert when the configured detection rule matches the event.

## Detection Scenario

A failed login attempt is generated against the monitored Windows endpoint.

```text
Windows Failed Logon
        ↓
Security Event ID 4625
        ↓
Wazuh Agent
        ↓
Wazuh Manager
        ↓
Custom Detection Rule 100016
        ↓
Wazuh Alert
```

## Custom Detection Rule

The lab uses custom Wazuh rule **100016** to identify the Windows failed-logon event.

```xml
<rule id="100016" level="8">
    <if_sid>60122</if_sid>
    <description>Custom Windows Failed Logon Detection</description>
    <group>windows,authentication_failed,custom_detection,</group>
</rule>
```

## Detection Logic

The rule is based on the Wazuh event generated from the Windows authentication failure.

| Field       | Value                  |
| ----------- | ---------------------- |
| Event       | Windows failed logon   |
| Event ID    | 4625                   |
| Rule ID     | 100016                 |
| Alert Level | 8                      |
| Category    | Authentication failure |

## Investigation

When the alert is generated, the analyst should review:

* Source IP address
* Target username
* Logon type
* Timestamp
* Hostname
* Authentication failure details
* Frequency of failed attempts

Repeated failed authentication attempts from the same source can indicate password spraying or brute-force activity and should be investigated further.

## Brute-Force Correlation

The lab also includes a correlation rule that can identify repeated failed logons from the same source IP.

```text
Multiple Event ID 4625
        ↓
Same Source IP
        ↓
Correlation Rule 100017
        ↓
Brute-Force Alert
```

This allows individual authentication failures to be correlated into a higher-confidence detection.
